# Icon
One sentence: renders a Lucide glyph in place of the source site's emoji icons.

```jsx
<Icon name="calendar" size={18} color="var(--green-700)" />
```

Requires `<script src="https://unpkg.com/lucide@latest/dist/umd/lucide.js"></script>` on the page. Common names used across this system: `calendar`, `users`, `map-pin`, `message-circle`, `trophy`, `cloud-sun`, `shuffle`, `shield`, `x`, `plus`, `chevron-right`, `megaphone`, `arrow-up`, `menu`.
