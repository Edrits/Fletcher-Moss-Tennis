# TopNav
One sentence: sticky header — circular badge + wordmark, desktop link row that collapses to a hamburger + dropdown below ~900px.

```jsx
<TopNav logo="assets/logo/fletcher-moss-logo.png" title="Fletcher Moss Social Tennis Club" subtitle="Didsbury Social Tennis"
  links={[{label:'About',href:'#about'},{label:'Sessions',href:'#sessions'},{label:'Pairings',href:'pairings.html'}]}
  active="About" />
```

Background is a subtle green gradient (not the source's flat colour) so it reads as one continuous surface with the hero scrim beneath it.
