# PM reports

Output of the `/pm` skill. See [.claude/skills/pm/SKILL.md](../.claude/skills/pm/SKILL.md).

- `BACKLOG.md` is the standing record. Read this first. It is the one file that stays current.
- `YYYY-MM-DD-sweep.md` files are point-in-time reports. They are history and are not updated after the fact.

The PM agent reports and plans. It does not change site code, commit, or deploy. Every fix it proposes is yours to approve and apply.
