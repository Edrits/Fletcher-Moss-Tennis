Sign-up logic tests

Browser harness for api/_lib/signup-core.js

RunningLoading module

How to run. Serve the repo root with python3 -m http.server 8000 and open /test-signup.html. The module is imported straight from api/_lib/signup-core.js, so opening this file from the file system will fail on the browser's module origin rules.

No network calls, no build step. Every clock is injected, so results do not depend on the time of day.
